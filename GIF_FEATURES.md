## Customization Guide

### Change a GIF
To replace any GIF, edit the `src` attribute in `index.html`:

```html
<img src="https://media.giphy.com/media/YOUR_GIF_ID/giphy.gif" alt="Description" class="service-animation">
```

Steps:
1. Find a GIF on Giphy.com
2. Copy the GIF URL
3. Replace the `src` value in the HTML
4. Save and refresh

### Add Animation Effects
Edit `style.css` for custom animations:

```css
.service-gif {
    animation: custom-animation 2s ease infinite;
}

@keyframes custom-animation {
    0% { transform: scale(1); }
    50% { transform: scale(1.05); }
    100% { transform: scale(1); }
}
```
